# 世界の違和感 Publishing Contract

## 目的

「世界の違和感」を単発SNS投稿ではなく、HDNが所有する編集レーベルとして積み上げるための正本契約です。

正本は `https://article.hdnjapan.com/` に置きます。note、LinkedIn Newsletter、LinkedIn通常投稿、Facebook、Xは正本の代替ではなく、発見・固定読者化・再接触のための配信面です。

## 正本metadata

公開する日本語正本は次を必須とします。

```yaml
audiences:
  - general
section: world-frictions
series: world-frictions
cta: editorial
contentType: news-analysis
```

`contentType` は記事内容に応じて `opinion`、`case-study`、`practical-guide`、`regulation` へ変更できます。

## 編集構造

基本の思考順序は次です。

違和感 → 具体例 → なぜそう感じるか → 構造 → 一次資料・研究・信頼できる報道 → ハッチの考察 → 読者への問い

順序は記事ごとに最適化してよく、固定テンプレートとして機械的に並べません。ただし、事実、推測、意見を混同しません。

## 事実確認

一次資料が存在する主張は、可能な限り一次資料を確認します。二次報道だけで断定しません。

匿名投稿、SNS投稿、体験談は「事例」または「違和感の入口」として扱い、裏付けのない事実認定には使いません。

記事末尾には原則として `## 出典・一次情報・参考文献` を置き、読者が元情報へ辿れる状態にします。

## CTA

`cta: editorial` を使用します。一般読者へ不自然なクリニック相談CTAを出しません。

優先順位は次です。

1. 同じ「世界の違和感」の関連記事
2. 著者・HDNについて
3. 正本RSSまたは購読導線
4. LinkedIn Newsletter
5. note

## 配信bundle

1本の正本から、次の派生物を作ります。

```text
social/<slug>/
  note.md
  linkedin-newsletter.md
  linkedin.md
  facebook.md
  x.md
  reposts.md
```

同一全文の一斉コピーは禁止します。それぞれの媒体で入口、長さ、文脈、CTAを変えます。

## 自動作成・自動公開

2026年9月12日以降、「世界の違和感」の通常運用は自動作成・自動公開を原則とします。定期実行ではハッチの事前確認を必須としません。

自動処理は「定刻になったから必ず記事を出す」仕組みにはしません。候補探索、一次資料・研究・信頼できる報道の確認、重複判定、原稿作成、独立した再レビュー、サイト検証を通過した記事だけを公開します。基準を満たさなければ公開しません。

標準の定期実行は月・水・金の17:30 JST、1回につき最大1本です。頻度より品質を優先します。

自動公開時も、日本語正本と英語版を同時に作成し、note、LinkedIn Newsletter、LinkedIn通常投稿、Facebook、X、再投稿用の派生原稿まで生成します。外部SNSへの直接投稿は、各媒体の正式な接続と公開権限が実装されたものだけを対象とし、未接続媒体へ投稿済みとは扱いません。

## 自動公開Gate

通常の「世界の違和感」は、人による最終承認の代わりに次のGateをすべて通過した場合のみ自動公開できます。

- 候補の編集スコアが86点以上
- 独立レビューの総合スコアが88点以上
- 独立レビューの事実確度が90点以上
- ソース品質が85点以上
- 評判・法務リスク評価が20点以下
- 3件以上の異なるHTTPSソースがある
- 少なくとも1件は一次資料または研究資料である
- 選択ソースのうち複数が実際のWeb検索結果と一致する
- 既存の「世界の違和感」とタイトル、論旨、主要ソースが実質重複しない
- 日本語・英語の正本metadataが契約どおり
- 事実、報道、推測、意見が混同されていない
- 名誉毀損、プライバシー、医療広告、薬機法、景表法等のリスクが許容範囲内
- world-frictions記事にclinic営業CTAが混入していない
- 派生物が正本と同じ全文の単純複製になっていない
- 完成原稿にアスタリスクによる強調表現を使用していない
- 外部配信版からHDN正本へ戻る導線がある
- OGP生成、型検査、テスト、Astro build、migration checkが成功している
- 本番デプロイ後に日本語記事、英語記事、OGP、World Frictions一覧のsmoke testが成功している

いずれかを満たさない場合、その回は正常終了として公開を見送ります。記事本数を埋めるために品質基準を下げません。

## 例外

重大な法務・医療安全・企業秘密・個人情報の懸念が機械的に解消できないテーマは自動公開の対象外とします。

ハッチが個別テーマを明示して記事化を依頼した場合も、通常の検証Gateは維持します。ただし、通常運用については「候補選定」「最終承認」を毎回ハッチへ求めません。
